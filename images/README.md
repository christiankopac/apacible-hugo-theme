# Theme Screenshots

This directory contains screenshots for the Hugo themes showcase.

## Required Images

- **screenshot.png** (1500x1000px) - Main theme screenshot
- **tn.png** (900x600px) - Thumbnail for theme gallery

## Creating Screenshots

1. Run the example site:
   ```bash
   cd exampleSite
   hugo server --themesDir ../..
   ```

2. Take screenshots at the required resolutions
3. Save them in this directory

## Guidelines

- Show the homepage or a representative page
- Ensure both light and dark mode are visible (or pick one)
- Keep content readable
- Avoid personal information
